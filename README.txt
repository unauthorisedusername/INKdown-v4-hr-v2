INKdown - GitHub APK build project

1. Create a new repository on github.com.
2. Upload ALL files from this folder (including the .github folder).
   If .github does not upload, create .github/workflows/build.yml manually
   and paste the contents of WORKFLOW.txt.
3. Open Actions tab, wait for "Build APK" (3-6 min).
4. Download artifact INKdown-APK, extract, install the .apk.

To update the app: replace index.html and commit.
